# Blockchain Ethereum & Solidity Learning Journey

This repository documents my learning journey in Ethereum blockchain development and Solidity smart contract programming through the Ethereum and Solidity course on Udemy.

## Projects

### 🎯 Lottery Smart Contract

A decentralized lottery application built with Solidity where participants enter by sending Ether to the smart contract. The contract manager can select a winner, who receives the entire prize pool.

#### Features
- Enter lottery using Ether
- Automatic participant tracking
- Manager-controlled winner selection
- Prize pool distribution
- Smart contract testing

#### Technologies
- Solidity
- Ethereum
- Hardhat
- MetaMask
- JavaScript

#### Concepts Learned
- Payable functions
- Contract deployment
- Ether transfers
- Arrays and state variables
- Smart contract testing

---

### 💰 Crowdfunding DApp

A decentralized crowdfunding platform that enables users to contribute funds to campaigns and allows campaign managers to create spending requests. Contributors vote on requests before funds can be released.

#### Features
- Create crowdfunding campaigns
- Accept Ether contributions
- Track contributors
- Create spending requests
- Contributor approval voting
- Secure fund transfers
- Campaign management dashboard

#### Technologies
- Solidity
- Ethereum
- React
- Next.js
- Web3.js
- Hardhat
- MetaMask

#### Concepts Learned
- Smart contract architecture
- Decentralized application (DApp) development
- Web3 integration
- Contract deployment
- Frontend-blockchain interaction
- Voting mechanisms
- Access control and security
